# 📊 Pandas for AI/ML – Conceptual & Technical Assessment

This repository contains my solutions for the **Pandas for AI/ML – Conceptual & Technical Assessment**.

The assessment focuses on using **Pandas and NumPy** for data manipulation, analysis, data cleaning, handling missing values, detecting invalid data, and solving practical data-analysis problems.

## 🎯 Objective

The main objective of this assessment is to strengthen practical knowledge of:

- Pandas DataFrames and Series
- NumPy arrays
- Data filtering and selection
- Statistical operations
- GroupBy operations
- Correlation analysis
- Data cleaning
- Missing-value handling
- Data type conversion
- Duplicate detection
- Outlier and invalid-value detection
- Real-world dataset analysis

## 📚 Assessment Sections

### Section A – Output Prediction
Covers basic Pandas and NumPy concepts such as:

- NumPy arrays vs Pandas Series
- Boolean filtering
- Mean, maximum, and median
- GroupBy and aggregation
- Correlation

### Section B – Code Correction
Contains incorrect Pandas code that was corrected using proper syntax and logic.

Topics include:

- Reading CSV files
- Sorting DataFrames
- Handling missing values
- Calculating correlation

### Section C – Edge Cases
Focuses on handling unusual or problematic data situations.

Topics include:

- NumPy broadcasting
- CSV parsing
- Mixed data formats
- Missing values
- Extreme salary values
- Mean vs median
- Data validation

### Section D – Scenario-Based Data Cleaning
A practical student-assessment dataset was cleaned and analyzed.

The process includes:

1. Loading the CSV dataset
2. Inspecting the dataset
3. Checking missing values
4. Standardizing department names
5. Detecting and removing duplicate records
6. Cleaning the `Marks` column
7. Handling values such as `Absent`, `NA`, and blank entries
8. Detecting marks outside the valid `0–100` range
9. Reporting the cleaned data
10. Summarizing the cleaning process
